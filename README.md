## Technology

The current starter documentation identifies React, Vite, TypeScript, Tailwind CSS, and shadcn/ui. Check the project dependencies before relying on this list.

## Getting started

1. Install a current version of Node.js and npm.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the local development server:

   ```bash
   npm run dev
   ```

4. Create a production build:

   ```bash
   npm run build
   ```

Available scripts are defined in `package.json`; confirm them before running commands.
